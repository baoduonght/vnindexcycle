# 📈 Automated Macroeconomic & Market Tracking System

## 🎯 Project Overview
This repository hosts an end-to-end automated Data Engineering pipeline designed to extract, transform, and load (ETL) complex macroeconomic indicators and financial market data. Built entirely on GitHub Actions, the system acts as a "Macro Radar," aggregating daily time-series data from global and local financial markets without any manual intervention. 

The dataset generated by this pipeline serves as the foundational infrastructure for Phase 2: building a Predictive Machine Learning model (Random Forest / RNN) to classify and forecast market liquidity and cash flow trends.

## 🏗️ Architecture & Tech Stack
* **Language:** Python 3.11
* **CI/CD & Automation:** GitHub Actions (Cron Jobs)
* **Data Sources (APIs):** 
  * **TradingView (via tvDatafeed):** Global macro indicators and local indices.
  * **FRED (Federal Reserve Economic Data):** US liquidity and banking system metrics.
  * **VNDirect API:** Institutional cash flows (Foreign & Proprietary trading).
* **Network Routing:** CORS Proxy Gateway (Geoblocking & Firewall bypass)
* **Data Storage:** Automated CSV continuous updates directly pushed to the repository.

## 🚀 Core Features
* **Automated ETL Pipeline:** Runs daily via GitHub Actions, scraping multiple data sources, cleaning missing values, and formatting time-series data into structured CSVs.
* **Defensive Programming:** Engineered with robust `try-except` blocks and API health checks. The pipeline ensures high SLA (Service Level Agreement) by isolating failing external nodes without crashing the entire system.
* **Geoblocking Bypass:** Implemented a Proxy Gateway to successfully extract local institutional trading flows by bypassing strict anti-DDoS firewalls from US-based cloud servers.
* **Zero Forward-Fill Policy:** Strict adherence to raw data integrity. Missing data points (e.g., weekends, non-publishing days) are kept as nulls to prevent artificial noise in future Machine Learning models.

## 📊 Data Dictionary (Extracted Variables)
The system outputs highly structured datasets (`macro_database5years.csv`) encompassing the following dimensions:
1. **Vietnamese Market (Local):** `VNINDEX`, `VN30`, `VN_VOLUME`
2. **Derivatives & Spread:** `VN30_F1M`, `DERIVATIVE_SPREAD` (Basis spread tracking)
3. **Institutional Flows:** `NET_FOREIGN_FLOW` (Foreign Net Buying), `NET_PROP_FLOW` (Proprietary Trading)
4. **Global Macro & Yields:** `VN10Y` (VN 10Y Bond), `US10Y` (US 10Y Bond), `US2Y`
5. **Currency & Commodities:** `DXY` (US Dollar Index), `USD_VND`, `JPY_USD`, `GOLD`, `OIL`
6. **Systemic Liquidity:** `FED_LIQUIDITY` (WALCL - WTREGEN - RRPONTSYD)

## 🔮 Next Steps: Predictive Analytics (Phase 2)
The aggregated historical data is currently being ingested into a **Google Colab** environment for feature engineering (lag features, momentum). The goal is to deploy a Machine Learning classifier to evaluate feature importance and predict the medium-term market trend (3-5 days outlook).
